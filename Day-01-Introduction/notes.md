
# Day 01 — Introduction to Programming and Python

## 1. What Is a Computer?

A computer is an electronic device that accepts data, processes it according to instructions, produces output, and can store information.

The basic operations are:

- Input
- Processing
- Output
- Storage

Example: A calculator accepts two numbers, performs an operation, and displays the result.

## 2. What Is Programming?

Programming is the process of writing instructions that a computer can execute to perform a task.

A program is a collection of instructions written in a programming language.

Examples of programming languages include Python, C, C++, Java, and JavaScript.

## 3. What Is Python?

Python is a high-level, general-purpose programming language known for readable syntax and a wide range of applications.

Python is used in:
- Artificial Intelligence
- Machine Learning
- Data Analysis
- Web Development
- Automation
- Scientific Computing

## 4. Advantages of Python

- Easy-to-read syntax
- Free and open source
- Large collection of libraries
- Cross-platform support
- Useful for many types of applications

## 5. Limitations of Python

- Can be slower than compiled languages for some tasks.
- May use more memory for certain applications.
- Is not the best choice for every performance-critical or embedded system.
- Programs may require additional libraries and dependencies.

## 6. What Is an IDE?

IDE stands for Integrated Development Environment.

It helps programmers write, execute, and debug code.

Examples: Spyder, PyCharm, and Visual Studio Code.

## 7. First Python Program

```python
print("Hello, World!")
```

Output:

```text
Hello, World!
```

The `print()` function displays information on the screen.

## 8. Important Terms

- Algorithm: A sequence of steps to solve a problem.
- Interpreter: Software that executes Python code.
- Script: A file containing program instructions.
- Output: The result produced by a program.

## Day 01 Summary

Today we learned what a computer does, what programming means, what Python is, its advantages and limitations, and how to write a first Python program.
